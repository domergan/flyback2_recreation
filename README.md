# EasyFlyback Recreation

An independent recreation of the Easy-Flyback driver by Franzoli Electronics: a resonant driver for CRT TV flyback transformers that produces high-voltage arcs, which can be audio-modulated to play music.

> **Not affiliated with or endorsed by Franzoli Electronics.**
> All credit for the original circuit design goes to Franzoli Electronics!

This repository contains a redrawn schematic and PCB layout based on the schematic that Franzoli Electronics published publicly on the [Easy-Flyback project page](https://franzolielectronics.com/easy-flyback-i/).
